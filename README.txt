MATRIX TEXTURE PACK INVENTOR
============================

Open index.html in a modern browser.

GitHub Pages setup:
1. Create a new GitHub repository.
2. Upload index.html and README.txt to the repository root.
3. Open Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select your main branch and the "/" (root) folder.
6. Save. GitHub will publish the site at your Pages address.

Main workflow:
1. Draw, paint, fill, erase, sample colors, or import an image.
2. Enter the Minefun asset filename/key and Minefun ID.
3. Click "Create Next Texture" to store the current texture and move to a fresh canvas.
4. Repeat for as many textures as needed.
5. Click "Finalize Texture Pack" to generate and download a Tampermonkey-compatible .user.js.

Editing:
- Ctrl+Z = Undo
- Ctrl+Y = Redo
- Ctrl+Shift+Z = Redo
- The Pack author is fixed to Matrix by default and is not shown as a user-editable field.

The generated UserScript contains Matrix attribution in metadata, comments, and a runtime marker.
